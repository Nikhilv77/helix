# Helix Product Notes

This is a living planning doc. Keep it lean. Add decisions here only when we actually decide them.

## Direction

Helix should help users practice interviews from their real resume evidence, not from generic question banks.

The core value:

- Maya reads what the user has done.
- Maya asks questions from that evidence.
- Maya pushes back when answers are vague, unsupported, or too generic.
- The user learns what to improve before a real interview.

## Scope

For now, improve the existing product instead of adding many new features.

Existing areas:

- Home
- Onboarding
- Profile
- Resume evidence
- Practice
- Progress
- Reports
- Interview session

## Product Rule

Every important item shown to the user should be tied to one of these:

- Resume evidence
- Interview risk
- Next practice action
- Feedback from a previous answer

Avoid random cards, generic advice, and filler text.
